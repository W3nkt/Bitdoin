# Bitdoin intake database contract

`/admin/book-intake` reads `public.books` rows where `is_active = false`. Bookstores later submit `public.book_prices`; intake must not create prices.

## Fields

| Column | Rule |
| --- | --- |
| `id` | Omit; generated by the database. |
| `isbn` | Nullable and unique. Store normalized digits; use the verified edition identifier. |
| `title` | Required; preserve the displayed title. |
| `author` | Nullable; credited author string. |
| `publisher` | Nullable; edition publisher/imprint. |
| `language` | Required; normally `Lao`, `English`, `Thai`, `Chinese`, or `French`. |
| `category_id` | Nullable FK to `public.categories(id)`; resolve from real rows. |
| `description` | Nullable safe HTML. Prefer verified publisher/bookseller `รายละเอียด` content and useful subsections; preserve its structure without navigation, pricing, or checkout text. |
| `pages` | Nullable positive edition-specific integer. |
| `publication_date` | Nullable ISO edition date. Disclose any year-only normalization. |
| `cover_image_url` | Nullable public HTTPS URL, never a filesystem path. |
| `is_active` | Always `false`. |

## Required SQL shape

```sql
begin;

insert into public.books (
  isbn, title, author, publisher, language, category_id,
  description, pages, publication_date, cover_image_url, is_active
)
values (
  null, 'Example title', null, null, 'Lao', null,
  null, null, null, null, false
);

select id, isbn, title, author, is_active
from public.books
where lower(title) = lower('Example title');

commit;
```

With an ISBN, append `on conflict (isbn) do nothing` and verify using ISBN. Escape apostrophes by doubling them. Dollar-quote long descriptions only with a delimiter absent from the content.

## Connection discovery

1. `supabase status` identifies a running local stack.
2. `supabase projects list` can show authenticated CLI access but does not authorize a remote mutation.
3. List only environment variable names, never values.
4. Ask the user to identify local/staging/production when multiple targets are possible.

Never use `supabase db reset`, destructive database commands, or migration-wide pushes for an intake insert. Execute only the reviewed SQL file against the explicitly selected database.
